## Search Tips for Users

1. **Use single flower names**: Instead of "beautiful roses", just type "rose"
2. **Combine for precision**: Type "rose eucalyptus" to find specific combinations
3. **Try partial names**: "sun" finds "sunflower"
4. **Use filters first**: Pick a category, then search within it
5. **Case doesn't matter**: "Rose", "ROSE", "rose" all work
6. **Spaces separate keywords**: "rose eucalyptus" searches for both
